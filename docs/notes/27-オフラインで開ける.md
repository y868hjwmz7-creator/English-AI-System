### 通勤・移動中に使えるようにした(第5.372節)

2026-10-04 利用者。**「売り出すとしたら何が足りないか」**のあと、
こちらから**4つ聞いた**。その2つめの答えがこれである。

> 通勤・移動中が多い

そして「次に作るもの」として、**A オフラインで開ける**を1番に選んだ。

#### なぜ、これがいちばん効くのか

**いまは電波が無いと、アプリが1行も開かない。**
地下鉄でアイコンを押すと、ブラウザの「接続できません」が出て終わる。
**ゲストがいちばん練習できる時間に、道具が無い。**

このアプリの中心は「レッスン → 宿題 → 次のレッスン」の循環であり、
**宿題に取り組む量**がそのまま効き目になる(CLAUDE.md 冒頭)。
通勤の往復は、1人あたり**週に5時間**ある。そこが丸ごと空いていた。

#### 3つの層に分けた。**どれも別々に効く**

| 層 | 何を控えるか | どこ |
|---|---|---|
| **枠** | 画面そのもの・部品・絵 | Service Worker(`app` / `asset`) |
| **音声** | 読み上げ MP3 と、文字ごとの時刻 | Service Worker(`clip`) |
| **中身** | 宿題の一覧・一度開いた教材 | IndexedDB(`localCopy.js`) |

**枠だけでは、空っぽの画面が開くだけ**である。
**中身だけでは、そもそも開かない。** 3つとも要る。

#### **控えてよいものと、絶対に控えないもの**

判断は **`src/lib/swPlan.js` の `routeOf()` 1か所**にある
(素の node で走る —— この環境では Service Worker を1度も動かせない)。

| 道 | 何 | なぜ控えてよいか |
|---|---|---|
| `asset` | `/assets/*.js` `*.css` | **名前に中身の指紋が入っている。**別物は別の名前 |
| `app` | 画面・絵・manifest | 名前が変わらない。**だから通信が先** |
| `clip` | 公開の置き場所の `.mp3` / `.json` | **置き場所が英文の指紋。**公開。鍵が要らない |
| `pass` | **それ以外ぜんぶ** | 触らない |

**`pass` が既定である。** 表のデータ(`/rest/v1/`)・ログイン(`/auth/v1/`)・
窓口(`/functions/v1/`)は**1バイトも控えない** ——
鍵が混じるし、RLS で人ごとに違うものが返る。
**控えると、別の人のものが出る。**

#### **古い版に固まらない**(ここがいちばん危ない)

CLAUDE.md が何度も踏んでいる穴
—— 「直したはずの不具合が直っていない = 古い内容が端末に残っていた」。
**Service Worker は、それを仕組みとして作り込める道具**である。
だから、はじめから4つ手を打った。

- **画面そのものは、必ず通信が先**(`app` = network-first)。
  電波があるときは**いつも最新**で、無いときだけ控えを出す
- **新しいのが来ても、勝手に入れ替わらない。**
  `install` で `skipWaiting()` を呼ぶと、**動いているページの下で古い控えが消える** ——
  そのページがこれから取りに行く部品は古い名前なので、**開いている最中に落ちる。**
  だから待たせて、「**新しい版があります → 読み込み直す**」を画面に出す
- **版が変われば控えの名前も変わり、古いのは `activate` で捨てる**
  (ただし**音声だけは版をまたぐ** —— 出し直すたびに捨てたら、ただの落とし直しである)
- **逃げ道を残した。** 画面から `{ type: 'unregister' }` を送ると、
  控えを全部捨てて自分を外す

#### **決まりを2か所に書かないために、組み立てで束ねた**

`public/sw.js` に手で置くと、`routeOf()` を**書き写す**ことになる。
だから `src/sw.js` に置き、`vite.config.js` が **esbuild で `dist/sw.js` に束ねる**
(Vite の入口にすると**名前に指紋が付き**、置き場所が毎回変わって登録できない)。

- 版(`VITE_BUILD_STAMP`)は **`define` でそのまま差し込む**
- **1ファイル版では作らない** —— `file://` では Service Worker が動かない
- **`charset: 'utf8'` が要る。** 既定だと日本語が `検` に逃がされ、
  **版が文字として読めなくなる**(検証で踏んだ)

#### 中身の控えは、**人ごとに分けて、ログアウトで捨てる**

会社の PC は**ゲストとトレーナーが同じ端末を使う**ことがある。
控えに人の印を付けないと、**次に開いた人に前の人の宿題が出る。**

- 鍵は `${その人の id}|${名前}`。**印が取れなければ、控えない・読まない**
- `signOut()` が、**Supabase へ行く前に**まるごと捨てる
  (届かなくても捨てる)
- **控えを出すのは、電波が無いときだけ。**
  断られた・行が無い・権限が無いは、**そのまま出す** ——
  そこで控えを出すと、**消えた教材がいつまでも見える**
- **控えだと分かるように出す**(「きょう 08:12 の控え」)。
  **黙って古い宿題を、今日のものとして見せない**

置き場所は **IndexedDB**。`localStorage` は**およそ 5MB** で、
しかも**書くあいだ画面が止まる** —— 宿題50件ぶんの英文と訳はそれを超える。
**使えなければ、控えないだけ**(内緒窓でも落ちない)。

#### 画面に出すもの

**「余計な説明書きは全て排除」**(利用者の指定)なので、
**いまの状態**と**押せる操作**だけ。決めるのは `offlineNote()` 1か所。

| いつ | 出すもの |
|---|---|
| 電波が無い | 「電波がありません」(押すものは無い) |
| 新しい版がある | 「新しい版があります」+ **読み込み直す** |
| 両方 | **電波のほう。** 電波が無いあいだ読み込み直しても、新しい版は降りてこない |
| どちらでもない | **何も出さない**(空の帯で場所を取らない) |

設定(三本線と丸)に「**オフラインの音声 ◯ 本**」と「消す」を置いた。
**見えない費用は管理できない**(CLAUDE.md)。
**消しても 0 円**(置き場所から落とし直すだけで、作り直してはいない)なので確認は置かない。
**数えられなければ、その行ごと出さない**(0 と `null` を取り違えない)。

#### 踏んだ落とし穴

**①`res.clone()` を、控える関数の中で呼んでいた。**

```js
async function put(cacheName, req, res) {
  const cache = await caches.open(cacheName)   // ← ここで待つあいだに
  await cache.put(req, res.clone())            // ← 画面が中身を読み始めている
}
```

`caches.open()` を待つあいだに**画面が body を読み始めていて、`clone()` が断られる。**
結果、**控えが1本も入らない。**
しかも**鳴るほうは成功している**ので、画面を見ても分からない ——
`clip-1` という**空の控えだけが残る。**
**写しは、呼ぶ側がその場で取る。**

**②`setOffline(true)` は、`127.0.0.1` を切らない。**

検証で「電波を切って測る」と書いていたが、**切れていなかった。**
サーバーが生きているので、**控えが1本も効いていなくても全部つながって緑**になる。
`navigator.onLine` だけは偽になるので、**画面の帯は正しく測れていた** ——
**だから気づきにくい。**

**本当にサーバーを止めて測る**ように書き直した。
音声は別の港に小さなサーバーを立て、控えたあとに**閉じる。**

**③`page.route` で差し替えたものを測っていた。**

あれは **Service Worker の外側で返る。** 電波を切っても返り続けるので、
**控えが効いていなくても鳴る。** 偽物ではなく、**本物のサーバー**を立てる。

**④`npx` を殺しても、中の vite は生き残る。**

CLAUDE.md に「残った vite を必ず殺す」と書いてあるのに、同じ形で踏んだ。
`--strictPort` なので、**居座りがいると新しいほうは立ち上がらず、
古いサーバーをそのまま測る。**
そのせいで「サーバーを止めて測る」節が**まるごと嘘**になっており、
**入口の控えへ戻す道を外しても緑のまま**だった(赤チェックで分かった)。

- **別の組(`detached`)で立てて、組ごと止める**(`SIGTERM` → `SIGKILL`)
- **立てる前に、港が空いていることを確かめる**(見張りを1本置いた)
- **止めたあと、本当に落ちていることを確かめる**(これも1本)

**⑤`page.goto` は、開けないと例外を投げる。**

受けずに書いていたので、④を直したあとの赤チェックで
**見張りが1行も出ないまま検証そのものが落ちた。**
「赤にならない」ではなく「**何も出ない**」。受けて、失敗として数える。

#### 見張り(`npm run test:offline`)

**`test:audio` が耳、`test:feel` が指なら、`test:offline` は地下鉄である。**

- 算段(素の node)… 道の選び方・控えの名前・溢れたぶん・登録してよい端末・
  電波の見分け・画面に出すもの
- 書き写していないか … `sw.js` が URL の見分けを自分で書いていないか、
  電波の言い方が2か所に無いか
- **実機**(組み立てて、`vite preview` で配って、Chromium で開く)
  - **本当にサーバーを止めて**、画面が描かれるか
  - 一度聞いた音声が、**サーバーが落ちても鳴るか**
  - **出ない側** … 聞いたことのない音声は鳴らない /
    **鍵の要るもの(表のデータ)は控えていない** /
    電波があるうちは、いつも新しいほうが出る

**5本の赤チェックを通してある。**

| 壊したもの | 赤くなった見張り |
|---|---|
| 既定を `clip` にする(鍵の要るものを控える) | 4本 |
| 画面そのものを控え優先にする | 「いつも新しいほうが出る」 |
| 写しを `put` の中で取る | 「サーバーが落ちても鳴る」「聞いた1本だけ」 |
| 入口の控えへ戻す道を外す | 「サーバーが落ちていても描かれる」 |
| 断られたのも「電波のせい」と見る | 「取り違えない」 |

#### **開いた教材の音声は、先に落としておく**(ボタンは足していない)

Service Worker が控えるのは**一度鳴らしたもの**だけである。
つまり**まだ聞いていない宿題は、電車で鳴らない。**

だから「**大きく表示する**」で開いた時点で、その教材の音声を先に落とす。

- **ボタンは足していない。**「余計な説明書きは全て排除」(利用者の指定)。
  開いた = その教材をやると決めた、ということである
- **0円**(置いてある MP3 を落とすだけ。作り直していない)
- **待たない。** 開くほうを1ミリも遅らせない(投げっぱなし)
- **端末が「データ節約」と言っていたら、何もしない**
  (`navigator.connection.saveData`)——
  **本人が止めている通信を、こちらで勝手に使わない。**
  判断は `swPlan.js` の `keepsAhead()` 1か所で、画面では決めない
- 何本控えてあるかは、設定の「オフラインの音声」に出る

落とす一覧は、**鳴らすときとまったく同じ道具**から引く
(`materialAudioClips()` → `wholeClipUrl()` / `materialRestClips()` → `clipUrl()`)。
**ここで別の数え方をすると、置いていない場所を落としに行く**(CLAUDE.md)。

#### **逃げ道は、アプリの外に置く**

控えが壊れていると、**アプリ自身が開けないことがある。**
**壊れているものに頼る逃げ道は、逃げ道にならない。**

だから `public/mic-test.html`(診断ページ)の第7節に、
**素の JS で直に捨てるボタン**を置いた
(`caches.keys()` と `navigator.serviceWorker.getRegistrations()` を
そのまま呼ぶ)。アプリ側の `dropOffline()` と、
Service Worker 側の `unregister` の受け口は**作ってから外した。**

#### **電波が無いと、控えの鍵が作れなくなる**(先に塞いだ)

控えを読むには**人の印**が要る。ところが印を取りに行く
`supabase.auth.getSession()` は、**切符の期限が切れていると取り直しに行く**
—— 電波の無いところでは、それが失敗する。
**つまり、控えがいちばん要る場面で鍵が作れない。**

- **最後に分かっていた人を覚えておく**(`localCopy.js` の `rememberWho`)。
  **ログアウトでは、控えと一緒に忘れる**
- **待ちすぎない**(2.5 秒で諦めて、覚えている人を使う)
- **人の印を待つあいだ、読み込みを止めない**(並べて走らせる)——
  待ってから読むと、その 2.5 秒がそのまま宿題の出るのを遅らせる
