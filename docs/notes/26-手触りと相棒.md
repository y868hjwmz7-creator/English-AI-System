#### **場所を動かす動きは、1つも作っていない**

利用者の指定「UI の配置が変化することをどの場所においても防いでください」。
だから動かすのは **`transform` と `opacity` だけ**にした ——
あの2つは**まわりの配置を1px も変えない。**
幅・高さ・余白・`display` は、動きの中で1つも触っていない。

#### **ミリ秒は `motion.js` 1か所にしか無い**

`styles.css` は `var(--motion-tap)` のように読むだけで、数を持たない。
`main.jsx` が**描く前に** `:root` へ流し込む(`useEffect` では最初の描画に
間に合わず、開いた瞬間だけ動きが無い、という食い違いが出る)。
**変数が無ければ動かないだけ** —— 画面は何も壊れない。

#### 相棒は、**言葉を持たない**

やり終えた1枚(`SessionResult`)には、もう**声かけ**がある(2026-09 の指定)。
相棒にも言葉を持たせると、**同じことをするものが2つ**になる(CLAUDE.md)。
だから相棒が持つのは**顔だけ**である。**顔は、言葉より速い。**

#### **「ユーザーが選べるようにしたい」で、3人から選ぶ形にした**(第5.373節)

2026-10-05 利用者。4案を見せたところ「どれもパッとしません」と言われ、
そのあと**こう言われた。**

> というよりユーザーが選べるようにしたいです

**こちらが1人に決める必要は、そもそも無かった。**

##### 「パッとしない」の中身は、好みではなく**作りの差**だった

4案はどれも「**丸に顔**」で、アイコンであってキャラクターではなかった。
直したのは4つで、**どれも好みの話ではない。**

| 足りなかったもの | 直したこと |
|---|---|
| **からだも手も無い** | 顔だけなので「何をしている子か」が出せない → **全身にして手を付けた** |
| **目にハイライトが無い** | いちばん効く。無いと必ず**死んだ目**になる → **白い点を2つ** |
| **まっすぐ正面で固い** | **首をかしげる**(listen は左、think は右) |
| **色が紺と薄い青だけ** | 地味 → **暖色**(2026-10-05 利用者の指定) |
| **輪郭線が無い** | 薄い地色だけだと、**手がからだに溶けて見えなかった** |
| **目が小さく、上にある** | **大きく・低く・離す**。これだけで一気に親しみやすくなる |

**3回作り直した。** 見せて、言われて、直す —— それ以外に道は無い。

##### 置き場所は、配色や説明の文とまったく同じ

**端末ごとに覚える**(`localStorage`)。**SQL は1行も要らない。**
会社の PC を何人かで使っても、開いている人が自分で選び直せる。

- **一覧は `buddyKind.js` 1か所。** 画面の中で `kind === '…'` と書かない
- **知らない値は既定に落とす** —— 古い端末に別の名前が残っていても、
  **相棒が1人も出ない**ことにはしない(行き止まりを作らない)
- **選ぶのは絵。** 言葉で選ばせない(「余計な説明書きは全て排除」)。
  名前は読み上げ(`aria-label`)にだけ置く
- **選ばせる絵は、本物の相棒そのもの。** 別の絵を置くと、選んだ先と食い違う

##### 呼び出し側を1つも変えずに済ませた

`SessionResult` は**3つの画面から呼ばれている。**
そこまで `kind` を手で渡して回ると、**渡し忘れた画面だけ違う相棒**になる。
`Buddy` 自身が `useBuddyKind()` で読む形にして、呼び出し側は 0 行の変更。
**見張りのために `kind` を渡せる口は開けてある**(3人とも描いて測れる)。

##### **小さいときは顔だけ**(同じ絵のまま切り出す)

全身を 28px に縮めると、ただの染みになる。
**`viewBox` で顔を切り出す** —— 別の絵を描くと、必ず片方だけ古くなる。

★ **`overflow: visible` を書くと、この切り取りが打ち消される**(作った日に踏んだ)。
きらめきも考えている点も、**`viewBox` の中に収める**ことで解決した。

##### 見張り(`npm run test:feel` に足した11本)

- 素の node … 3人とも居る / id が重ならない / 名前がある /
  **知らない値でも必ず誰かに落ちる** / 画面が覚える場所を触らない
- 実機 … 3人 × 6つの顔がぜんぶ描かれる /
  **相棒が違っても顔が違っても、箱の大きさは 1px も動かない** /
  **小さいときは相棒ごとに切り出している**(全身のまま縮めていない)/
  **選び直すと、同じ画面の相棒がその場で変わる** /
  選び直しても、えらぶ行の大きさは動かない

**4本の赤チェックを通してある**(相棒を1人減らす / 知らない値を素通しする /
切り出しをやめる / 合図を外す)。

##### 震えは `handLine.js` 1か所に持たせた

12 人ぶんの線を手で歪ませると、**足した1人だけ妙にきれい**になる。
形のほうは素直に書いて、**震えは通すだけ**にした。

- **`Math.random()` を使わない。** 描き直すたびに相棒が歪み直す ——
  画面を触るたびに顔が変わるのは、気味が悪いだけである。
  **種から決まる数**にして、同じ相棒はいつも同じ顔にする
- 点を**直線で結ばない。** 折り紙のように角ばる ——
  **中点を通る曲線**にすると、手で一筆書きした線に見える
- **きれいな円を1つも使わない**(点を 13 個ならべて、ずらす)

##### 顔は真顔。**ハイライトを外した**

大きな目に白いハイライトを入れるのは、
**第5.373節で「死んだ目になる」と言って足したもの**である。
ところが**それが「整ったかわいさ」の正体**だった。
今回は外して、代わりに

- 目は**大きさも高さも違う**点2つ
- **鼻を1本の線で入れる**(あちらの絵の、いちばん効いている部分)
- 口は**短い線。少し曲がっている**

**前に足したものが、次の指定では邪魔になることがある。**
「良いもの」ではなく「**いま向かっている方へ効くか**」で決める。

    おばけ / おむすび / たまご / めがね / ひげ / かぶ

##### 見張り(`test:feel` に足した6本)

**震えは、止めても画面は出る** —— だから機械で見る。

- 同じ種なら、いつも同じ形 / 種が違えば、形も違う
- ★ **線が、本当に震えている**(きれいな円との差を測る)
- 震えすぎて、形が崩れていない
- きれいな円ではなく、点を並べて描く
- 点が少なすぎたら線を引かない / 何も渡されなくても落ちない

**3本の赤チェックを通してある**(震えを止める / 描くたびに形が変わるようにする /
相棒を1人減らす)。

#### 踏んだ落とし穴

**①`animation-fill-mode: both` が、`:active` を永久に打ち消していた。**

登場の動き(`rise-in`)を `both` で止めていたので、
**終わったあとも最後のコマ(`transform: none`)が居座り**、
押しても沈まなかった。しかも **`:active` には「なっている」** ——
`getComputedStyle` を出して、初めて `matrix(1,0,0,1,0,0)` のままだと分かった。

動きは**書いた決まりより強い**(cascade の origin が上)ので、
後ろに書いても・細かく書いても勝てない。**`backwards` にする** ——
遅らせているあいだだけ最初のコマを当て、終わったら何も残さない。

**②ヘッドレスの既定は「動きを減らす」である。**

知らずに測ると**いつも「動かない」が返り、見張りが素通りする。**
`reducedMotion` を**明示して2通り**(動かす / 減らす)走らせる。

**③読み込みを待つと、もう駆け上がり終わっている。**

`waitUntil: 'networkidle'` のあとで点を読むと、いつも終わりの値だった。
**描く前から見張る**(`addInitScript` で 35ms ごとに控える)。

**④0 と `null` を取り違えた。**

`Number(null)` は **0** になるので、**点を渡していないだけの場面が
「0 点だった」と読まれ、やり切ったのに励まされていた。**
CLAUDE.md に書いてあることを、作った日にそのまま踏んだ。

**⑥飾りの線を、顔の線と同じ名前にしていた**(第5.374節)。

塗りつぶしの相棒では、顔の線を**白**にする(紺の上に乗るため)。
ところが**からだの外にある飾り**(触角・ひげ・葉・腕)も同じ名前だったので、
**一緒に白くなって、紙に溶けて消えた** ——
うちゅうじんの触角が**1本も見えなかった。**
**外にあるものは、いつも紺**(`buddy-out`)。

**⑦その赤チェックが、1度空振りした。**

「飾りが消えていないか」を、**箱の背景と比べて**書いていた。
**箱の背景は透明**なので、飾りを何色にしても一致しない ——
**どんなに壊しても緑のまま**だった。
比べる相手は「**線だけの相棒の、同じ飾り**」である
(塗りつぶしかどうかで色が変わっていないことを、そのまま測る)。
CLAUDE.md「見比べる相手は、できるだけ近いもの」を、そのまま踏んだ。

**⑤コメントを落とさずに数えた。**

CSS の層の説明には「押して 220ms 後に測る」のような**数**が書いてある。
落とさずに数えたので、**説明文に当たって、いつも赤くなった。**

**名前を知らない妖怪は入れていない。** 並べても選びようがない。

##### 顔は1か所で描いて、妖怪ごとの場所へ**置く**

全身になったので、顔の置き場も大きさも妖怪ごとに違う
(ろくろくびの顔は小さく、ぬりかべの顔は大きい)。
それでも**顔を12通り書き写さない** —— 各体が `顔: { cx, cy, s }` を1つ持ち、
`Face` がそこへ描く(CLAUDE.md「判断は1か所に持つ」)。

**`<g transform="scale()">` で縮めてはいけない。**
あれをやると**線の太さまで縮み**、顔の小さい妖怪(ろくろくび)だけ
線が細くなって、並べたときにそこだけ弱って見える。
**点のほうを計算して置く**(`Face` の `P()`)。線の太さは 12 体とも同じ。

顔の違いは2つだけ。**どちらも `形` が持つ。**

- `目数: 1` … からかさ・ひとつめこぞう
- `鼻: false` … てんぐ(**自前の長い鼻**がある)

##### **小さいときに、顔だけ切り出さない**

第5.374節で顔だけにしたとき、「28px でもそのまま読める」と書いた。
**立ち姿に戻しても、切り出しは入れない。**
妖怪は**形で見分ける**ものなので、顔を抜くと
**ぬりかべといったんもめんの区別がつかなくなる** ——
えらぶ画面が、まさにそれである。えらぶ列を 42 → **48px** に上げた。

##### **描いて、1体ずつ直した**(ここがいちばん長かった)

**推測でいじらない。まず描いて見る**(CLAUDE.md)。
1回目に出した 12 体のうち、**5体が「何の妖怪か分からない」形**だった。

| **ろくろくびの首が、結び目**になった | うねりを大きくして、**左右の縁が交わっていた** |

直し方も、そのまま決まりになる。

- **角の要るものは `手の四角()`。** 辺の途中にも点を置くと、

#### **「媚びている」「個性が潰れている」—— こちらの手で潰していた**(第5.378節)

18 体を出したところ、利用者から。

> 表情を可愛くしすぎです。媚びているように見えます
> また、妖怪っぽさが全然なく、**個性が潰れています。**
> 笑顔など入りません。**笑顔はない、でもだんだん親しみが湧く相棒。**
> **爬虫類をペットにしている人の気持ち**と似ているかもしれません

**失敗は2つ、どちらもこちらの手による。**

##### ①「真顔にする」と書きながら、口だけ笑わせていた

第5.375節から3回続けて「笑わせない」「真顔」と書いている。
それでも `glad` / `proud` / `cheer` の口は**上向きの弧**のままだった。
**書いた決まりを、自分で読み返していなかった。**

直し方は、**口を1度も曲げないこと**にした。

| 顔 | まぶた | 瞳 | 口 |
|---|---|---|---|
| `rest`   | ふつう | 細い | 真一文字 |
| `listen` | ふつう | 中 | 小さく縦に開く |
| `think`  | **片目だけ下がる** | 細い | 斜めの直線 |
| `cheer`  | **見開く** | **太い** | 縦に開く |
| `glad`   | **水平に閉じる** | — | 真一文字 |
| `proud`  | **半分** | 細い | 真一文字 + きらめき |

**表情は、まぶたと瞳の太さだけで出す。**
閉じた目も**上向きの弧にしない** —— あれが笑顔の正体である。

##### ②型紙をそろえて、個性を潰した

第5.377節で `着物()` `足()` `帯()` `腕()` を作り、18 体で共有した。
理由は「足した1体だけ丈が違う」を避けるため。
**そろえた結果、ぬりかべもいったんもめんも、
同じ人形に別の帽子を載せた絵になっていた。**

**線の作風をそろえることと、からだの型紙をそろえることは、別である。**
見本の一覧も、線はそろっていて**形は1つも同じでない。**

型紙は捨てて、**1体ずつ別のからだを書いた** ——
ぬりかべは横長の壁、ろくろくびは首が画面いっぱい、
いったんもめんは1枚のうねる布、きゅうびは四つ足、うみぼうずは波から出た塊。

##### 爬虫類の目にした(この版の肝)

**縦のスリットの瞳。** 笑わないのに瞳の太さで分かり、
**少しだけ不気味で、見ているうちに情が湧く。**
利用者の言う「爬虫類をペットにしている人の気持ち」は、これだと判断した。

##### 暖色を1色だけ。**1体につき1か所**

利用者「ポップに」。色は、以前いただいた指定(**暖色・橙または黄**)。
皿の水・腰巻・舌・鬼火・腹 —— それぞれ1か所だけである。
**たくさん塗ると、とたんに子ども向けになる。**

`--warn`(#eda100)を使い回していない —— あれは「気をつけて」の意味を
持っており、**相棒の腰巻が警告色になると、意味のほうが先に効く。**

##### **妖怪ごとの癖**(だんだん親しみが湧く仕掛け)

止まっている絵は、何度見ても同じである。
**1体につき1か所だけ、ゆっくり動く場所**を持たせた ——
皿がゆれる / 尾がゆれる / 舌がのびる / 涙が落ちる / 布がうねる。
**押したときではなく、ただ置いてあるときに動く。**
気づくのは2回目か3回目で、そこから情が湧く。

癖は**4種類だけ**(`sway` / `pulse` / `drift` / `drip`)——
18 通り書くと、足した1体だけ動きが違う。
**動きを減らす設定の人には、1つも動かさない。**

##### 見張り(`test:feel` に足した9本・65 → 76本)

- ★★ **口が1つも笑っていない。** **文字で見張らない** ——
  「`手の線` を使っているか」では、点の並び次第でいくらでも笑う。
  **描かれた線そのものを測る**(`getPointAtLength`)——
  口の道の、まん中と両端の高さを比べ、**まん中が下がっていたら笑顔**である
  (**赤チェック済み**。口を弧に戻したら、ちゃんと赤くなった)
- ★ **シルエットは、妖怪ごとに違う**(絵の広がりを測り、半分以上が別の寸法)——
  同じ型紙を使い回すと、ここが一斉にそろう
  (**赤チェック済み**。18 体を1つの型紙にしたら赤くなった)
- **18 体とも、癖を1つ持っている / 癖は1種類に寄っていない /
  癖は本当に動く決まりを持っている**(クラスだけ付いていても 1px も動かない)
- **動きを減らす端末では、妖怪の癖も止まる**(出ない側)
- **暖色が、ちゃんと色として出ている / 線の色とも紙の色とも違う**
- **外の飾りは、紙の色にも塗りつぶしのからだにも溶けない**
  (測る相手が変わった —— 塗りつぶしがうみぼうず1体になり、
  その外の飾りは**暖色の波**である。前の形のままだと何も取れずに赤くなる。
  **見張りは、いま本当に在るものを測る**)

##### ここから持ち帰ること

- **「真顔にする」と書くだけでは、真顔にならない。**
  **描かれたものを測る見張り**を置いて、初めて守られる
- **そろえると、個性が消える。** そろえてよいのは**作風**であって、**形ではない**
- **止まっている絵には、情が湧かない。** 動かすのは1か所でよい

#### 見張り(`npm run test:feel`・76本)

**`test:audio` が耳の代わりなら、`test:feel` は指の代わりである。**

- 算段(素の node)… 長さの順・数え上げ・遅れの上限・顔の決まり方
- CSS … **押した返り・登場・祝福の長さを書き写していない**
- **実機** … 押しているあいだの `transform` を**そのまま測る**
  (「CSS に `:active` の決まりがある」では見張ったことにならない)
- **出ない側** … 動きを減らす端末では沈まない / 駆け上がらない

4本の赤チェックを通してある。**①の不具合を戻すと、ちゃんと赤くなる。**
