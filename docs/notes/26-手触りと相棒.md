#### **場所を動かす動きは、1つも作っていない**

利用者の指定「UI の配置が変化することをどの場所においても防いでください」。
だから動かすのは **`transform` と `opacity` だけ**にした ——
あの2つは**まわりの配置を1px も変えない。**
幅・高さ・余白・`display` は、動きの中で1つも触っていない。

#### **ミリ秒は `motion.js` 1か所にしか無い**

`styles.css` は `var(--motion-tap)` のように読むだけで、数を持たない。
`main.jsx` が**描く前に** `:root` へ流し込む(`useEffect` では最初の描画に
間に合わず、開いた瞬間だけ動きが無い、という食い違いが出る)。
**変数が無ければ動かないだけ** —— 画面は何も壊れない。

#### 相棒は、**言葉を持たない**

やり終えた1枚(`SessionResult`)には、もう**声かけ**がある(2026-09 の指定)。
相棒にも言葉を持たせると、**同じことをするものが2つ**になる(CLAUDE.md)。
だから相棒が持つのは**顔だけ**である。**顔は、言葉より速い。**

**動物のゆるキャラにしていない。** 使うのは働いている大人で、
会社の英語スクールの道具である —— 角の丸い四角に目が2つだけの
抽象的なかたちにし、**色はアプリの色をそのまま使った**(新しい色は1つも無い)。

#### 踏んだ落とし穴

**①`animation-fill-mode: both` が、`:active` を永久に打ち消していた。**

登場の動き(`rise-in`)を `both` で止めていたので、
**終わったあとも最後のコマ(`transform: none`)が居座り**、
押しても沈まなかった。しかも **`:active` には「なっている」** ——
`getComputedStyle` を出して、初めて `matrix(1,0,0,1,0,0)` のままだと分かった。

動きは**書いた決まりより強い**(cascade の origin が上)ので、
後ろに書いても・細かく書いても勝てない。**`backwards` にする** ——
遅らせているあいだだけ最初のコマを当て、終わったら何も残さない。

**②ヘッドレスの既定は「動きを減らす」である。**

知らずに測ると**いつも「動かない」が返り、見張りが素通りする。**
`reducedMotion` を**明示して2通り**(動かす / 減らす)走らせる。

**③読み込みを待つと、もう駆け上がり終わっている。**

`waitUntil: 'networkidle'` のあとで点を読むと、いつも終わりの値だった。
**描く前から見張る**(`addInitScript` で 35ms ごとに控える)。

**④0 と `null` を取り違えた。**

`Number(null)` は **0** になるので、**点を渡していないだけの場面が
「0 点だった」と読まれ、やり切ったのに励まされていた。**
CLAUDE.md に書いてあることを、作った日にそのまま踏んだ。

**⑤コメントを落とさずに数えた。**

CSS の層の説明には「押して 220ms 後に測る」のような**数**が書いてある。
落とさずに数えたので、**説明文に当たって、いつも赤くなった。**

#### 見張り(`npm run test:feel`・37本)

**`test:audio` が耳の代わりなら、`test:feel` は指の代わりである。**

- 算段(素の node)… 長さの順・数え上げ・遅れの上限・顔の決まり方
- CSS … **押した返り・登場・祝福の長さを書き写していない**
- **実機** … 押しているあいだの `transform` を**そのまま測る**
  (「CSS に `:active` の決まりがある」では見張ったことにならない)
- **出ない側** … 動きを減らす端末では沈まない / 駆け上がらない

4本の赤チェックを通してある。**①の不具合を戻すと、ちゃんと赤くなる。**
