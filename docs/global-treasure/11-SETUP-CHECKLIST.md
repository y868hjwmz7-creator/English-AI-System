## 2. いちばん大事な結論

> **「自分の持ち物を海外に売る」ところから始めれば、古物商許可を待たずに検証できる。**

一般に、**自分がもともと所有していた物を売却する行為**は古物営業に当たらないと解されている。
一方、**転売目的で継続的に仕入れる行為**（＝ HUNT モード）は許可が必要になる可能性が高い。

`要確認`（最優先）: この線引きは管轄の警察署（生活安全課）で必ず確認すること。
「自分で使っていた物を売る」「フリマで買った物を売る」「利益目的で仕入れた物を売る」の
どこからが古物営業になるかを、**具体的な行為で説明して聞く**のが確実。

### したがって、順序をこう組む

```
今すぐ ───────────────────────────────────────────────►
  ①古物商許可を申請する（時間がかかるので最初に出す）
  ②開発を始める（MY STUFF → 海外出品の一本道）
  ③自分の持ち物3件を実際に eBay で売り切る  ← 許可なしで検証できる
        ↓ 許可が下りたら
  ④HUNT モード（仕入れ判断）を解禁する
```

**MVP の設計は変えない。検証の順番だけを変える。**
バックログ（[10](10-BACKLOG.md)）でいえば、M5「送れる」までを自分の持ち物で通し、
HUNT の実地検証（店頭での仕入れ）だけを許可取得後に回す。

## 3. すぐ着手するもの（今週）

### A-1. 古物商許可の申請 — **時間がかかるので最初に出す**

| 項目 | 内容 |
|---|---|
| 何のため | HUNT モード（仕入れ→転売）の実運用に必要になりうるため |
| どこで | **営業所の所在地を管轄する警察署の生活安全課** |
| 期間の目安 | 申請受理から **40 日前後**と言われる（`要確認`: 管轄により異なる） |
| 費用の目安 | **19,000 円程度**の申請手数料（`要確認`） |
| 主な必要書類 | 住民票、身分証明書、誓約書、略歴書、営業所の使用権限を示す書類 など（`要確認`） |
| 注意 | **インターネットで取引する場合、使用する URL の届出が必要**とされる。アプリ／サイトのドメインを先に決めておくと手戻りがない（`要確認`） |
| 未取得だと | HUNT モードの**実地検証ができない**。開発と MY STUFF の検証はできる |

> **先にドメインを決めておく。** 後から URL を追加する届出が要る場合、手間が二度になる。
> 例: `globaltreasure.jp` など（取得可否は要確認）。

### A-2. eBay の開発者登録

| 項目 | 内容 |
|---|---|
| 何のため | 相場データの取得と出品 API（[09](09-LEGAL-CHECKLIST.md) L-2） |
| 費用 | 通常は無料（`要確認`） |
| 期間 | 登録自体は即日。**本番キーの発行やデータ系 API の利用には審査がある場合がある**（`要確認`） |
| 未登録だと | **バックログ EPIC-0 の 0-2 が始められない**。＝ 対象カテゴリを確定できない |
| 個人でも可か | `要確認`（個人事業主として登録できるかを確認する） |

**これが最優先の技術タスク。** 相場データが取れるかどうかで設計の前提が変わる。

### A-3. 販売用の eBay アカウント（自分が売る側として）

開発者登録とは別に、**実際に売るためのアカウント**が要る。
本人確認・支払い受取の設定に日数がかかることがあるため、早めに作っておく。

`要確認`: 日本在住者が eBay で販売する際の本人確認・受取口座の要件。

### A-4. 開業届・青色申告（税務）

| 項目 | 内容 |
|---|---|
| 何のため | 個人事業主としての所得の申告 |
| どこで | 税務署（e-Tax でも可） |
| 補足 | すでに個人事業主として届出済みであれば、**事業内容に物販が含まれるか**を確認する |
| `要確認` | 転売益の所得区分、輸出取引と消費税の扱い、インボイス制度との関係 → **税理士** |

## 6. 何がなくても、何ができるか（依存関係）

| やりたいこと | 必要なもの | 今できるか |
|---|---|---|
| VALUE ENGINE を作る（EPIC-2） | なし | ✅ **今日からできる** |
| 相場データの調査（EPIC-0） | eBay 開発者登録（A-2） | 登録後すぐ |
| アプリの開発（EPIC-1〜6） | なし（Expo Go で動く） | ✅ できる |
| 実機でカメラを試す | Apple / Google の開発者登録（B-1/B-2） | 登録後 |
| 自分の持ち物を海外に売る（M5 検証） | eBay 販売アカウント（A-3） | ✅ **許可なしでできる**（`要確認`） |
| HUNT モードの実地検証 | **古物商許可**（A-1） | 許可取得後 |
| 他人に配布する（β） | ストア登録 + 規約 + プライバシーポリシー | M6 の頃 |
| 課金する | 上記 + 特商法表記 | 公開後 |

## 7. 今週やることリスト

- [ ] 管轄の警察署に電話し、**古物商許可が必要になる線引き**を具体的な行為で確認する
- [ ] ドメイン名を決めて取得する（古物商の URL 届出に間に合わせるため）
- [ ] 古物商許可の必要書類を確認し、住民票などの取得を始める
- [ ] eBay の開発者登録を行い、**カメラ 20 型番のデータが取れるか**を試す（EPIC-0 の 0-2）
- [ ] eBay の販売用アカウントを作り、本人確認を通しておく
- [ ] 税理士に、転売益の所得区分と輸出取引の消費税について相談する

**この 6 つが終われば、設計の前提が「調べたこと」に置き換わる。**
そこで設計書を改訂し、実装フェーズに入る。
