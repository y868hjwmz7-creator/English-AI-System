# 教材の自動生成をつかえるようにする

トレーナーが「弱点タグを選ぶ → ボタンを押す」だけで、
40問の下書きができるようにするための設定です。

**この設定は最初の1回だけです。** 以後、トレーナー50人はこの作業に関わりません。

---

## 全体の流れ

```
① Anthropic のアカウントを作り、鍵を取る       (あなた・5分)
② Supabase に鍵を預ける                        (あなた・2分)
③ 受付窓口(generate-material)を配置する      (あなた・5分)
④ アプリから試す
```

**鍵はあなたの手元 → Supabase の中、で完結します。**
ブラウザにも GitHub にも私のところにも出ません。

---

## ① Claude の鍵を取る

1. https://console.anthropic.com/ を開き、アカウントを作る(メールで登録)
2. 左メニュー **API Keys** → **Create Key**
3. 名前は `english-ai-system` など分かるもの
4. **表示された鍵をコピーする**

> ⚠️ **この鍵は作成時にしか表示されません。** その場でコピーしてください。
> なくしたら作り直せます(古いほうは削除します)。

> ⚠️ **この鍵はチャットに貼らないでください。** 管理者の鍵と同じ扱いです。
> 貼る先は次の②(Supabase の画面)だけです。

### 費用について

使った分だけの後払いです。**最初にクレジットを買う必要があります**
(Console の **Billing** から。最小額で始められます)。

見積り(仕様書 第5.13.4節):

| | |
|---|---|
| 教材1つ(40問) | 約 $0.1 |
| 定常期(全体で週27教材) | **月 約 $9** |

**使いすぎが不安な場合**は、Console の **Limits** で
月の上限額を決められます。最初は低めに設定しておくと安心です。

---

## ② Supabase に鍵を預ける

1. Supabase の画面 → 左メニュー **Edge Functions**
2. **Secrets**(または Settings の中)を開く
3. **Add new secret** で登録する

| Name | Value |
|---|---|
| `ANTHROPIC_API_KEY` | ①でコピーした鍵 |

**名前は1文字も間違えないでください。** 大文字・アンダースコアまで一致が必要です。

> ここに入れた鍵は、Supabase のサーバー上の関数からしか読めません。
> アプリのブラウザ側からは見えません。

---

## ③ 受付窓口を配置する

配置するのは2つです。

| 関数 | 役目 |
|---|---|
| `create-user` | アカウントの発行(第 5.8 節) |
| `generate-material` | 教材の下書き生成(この文書) |

### 方法1:Supabase の画面から(できればこちら)

1. 左メニュー **Edge Functions** → **Create a new function**
2. 名前に `generate-material` と入れる
3. 出てきた編集画面に、リポジトリの
   `supabase/functions/generate-material/index.ts` の中身を貼る
4. **同じフォルダの `prompt.ts` も必要です。**
   画面でファイルを追加できる場合は `prompt.ts` として追加する
5. **Deploy** を押す

> **画面にファイルを追加する機能が無い場合**は、方法2になります。
> `index.ts` は `prompt.ts` を読み込んでいるため、1ファイルでは動きません。

### 方法2:あなたの Mac から

Mac に Node.js と Supabase CLI を入れて、リポジトリを取得したうえで:

```
npx supabase login
npx supabase link --project-ref tsfoecjabgcdmvxdcpgy
npx supabase functions deploy generate-material
npx supabase functions deploy create-user
```

手順が必要でしたらご案内します。

---

## ④ アプリから試す

1. アプリを開き、**教材** タブ → **＋ 教材を新しく作る**
2. **種類**を「文型ドリル」にする
3. **弱点タグ**を1つ選ぶ(例:to不定詞)
4. **レベル**と**業界**を選ぶ
5. **「下書きを作る(40問)」**を押す

1〜2分で、4つの演習(和訳・穴埋め・英訳・リスニング)が並びます。

### そのあと必ずすること

**目を通して直してください。** 共有した教材は他のトレーナーの生徒にも届きます。
悪い教材1つが1,500人(将来4,500人)に届く仕組みなので、ここは省けません。

同じ文型が並ぶので、**1問目を直せば残りは流し読み**で済みます。

---

## うまくいかないとき

| 画面に出る文 | 原因 | どうするか |
|---|---|---|
| 生成の窓口につながりませんでした | ③がまだ | 関数を配置する |
| Claude の鍵が設定されていません | ②がまだ | Secrets に登録する |
| Claude の鍵が正しくありません | 鍵の写し間違い | ①からやり直す |
| Claude の残高が不足しています | クレジット切れ | Console の Billing で追加 |
| 短い時間に作りすぎました | 連続で押しすぎ | 少し待つ |
| 教材を作る権限がありません | 役割が生徒のまま | `role` を確認する |
