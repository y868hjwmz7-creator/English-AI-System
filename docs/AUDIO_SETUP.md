# お手本音声を用意する手順

練習用の英文の音声をあらかじめ作り、全端末で同じ品質にするための手順です。

> **なぜ必要か**
> 端末に入っている音声は品質がばらばらです。特に iPhone では、
> 利用者が高品質な音声をダウンロードしても、Apple の制限により
> ブラウザからは使えません(仕様書 3.3.4)。
> あらかじめ音声を作って配信する以外に、品質を揃える方法がありません。

---

## 用意する話者(4人)

| 表示名 | アクセント | 性別 |
|---|---|---|
| Emma | アメリカ英語 | 女性 |
| Ryan | アメリカ英語 | 男性 |
| Sophie | イギリス英語 | 女性 |
| Oliver | イギリス英語 | 男性 |

地域訛り(スコットランド英語など)は後回しにしています(仕様書 7.1)。

---

## 費用

**無料枠に収まります。**

Azure の音声合成は1文字あたりで課金され、**毎月50万文字までは無料**です。

| | 文字数 | 費用 |
|---|---|---|
| いまの例文8件 × 4人 | 約1,600文字 | **$0** |
| 例文500件 × 4人 | 約12万文字 | **$0** |
| 例文2,000件 × 4人 | 約48万文字 | **$0** |

**一度作れば作り直す必要はありません。** 英文を足したときだけ、
足した分の音声が作られます。

## 手順

### 1. Azure のアカウントを作る

1. `https://azure.microsoft.com/ja-jp/free/` を開く
2. 無料アカウントを作る(クレジットカードの登録を求められますが、
   無料枠の範囲では請求されません)

### 2. 音声サービスを作る

1. Azure ポータルで「リソースの作成」→「Speech」を検索
2. 次のように設定する

| 項目 | 値 |
|---|---|
| リージョン | **Japan East**(日本から使うため) |
| 価格レベル | **Free F0**(無料枠) |

### 3. 鍵とリージョンを控える

作成したリソースの「キーとエンドポイント」を開き、次の2つを控えます。

- **キー1**(長い文字列)
- **場所/地域**(例: `japaneast`)

### 4. `.env` に書く

リポジトリの `.env`(無ければ `.env.example` をコピーして作る)に
次の2行を書きます。

```
AZURE_SPEECH_KEY=控えたキー1
AZURE_SPEECH_REGION=japaneast
```

> **`.env` は Git に入りません。** 鍵が公開リポジトリに載ることはありません。
> 逆に、鍵をこのファイル以外の場所に書かないでください。

### 5. 音声を作る

```
npm run audio
```

`public/audio/` の下に、話者ごとのフォルダと音声ファイルができます。
あわせて `manifest.json`(目録)が作られます。

### 6. 反映する

できた音声ファイルをコミットしてプッシュすれば、公開ページに反映されます。

```
git add public/audio
git commit -m "お手本音声を追加する"
git push
```

---

## 音声ができると何が変わるか

- お手本の枠に「**全端末で同じ品質**」と表示されます
- 話者が Emma / Ryan / Sophie / Oliver の4人になります
- iPhone でも Android でも、同じ音声が再生されます

音声が用意されていない英文については、**端末内蔵の読み上げに切り替わります**。
アプリが止まることはありません。

---

## 英文を追加したとき

`src/data/practicePhrases.js` に英文を足したら、`npm run audio` を
もう一度実行してください。**足した分だけ**音声が作られます。
