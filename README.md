# English AI System

英語学習の記録・発音練習アプリと、指導者向けの管理ダッシュボードです。
現在は**試作版(プロトタイプ)**の段階です。

---

## まず動くものを見たい方へ

**あなたのパソコンには、何もインストールする必要はありません。**
次の3つのうち、やりやすい方法を選んでください。

### 方法1: 1ファイル版をダウンロードして開く(いちばん手軽)

1. 次のURLを開く
   `https://y868hjwmz7-creator.github.io/English-AI-System/download.html`
2. ブラウザの保存機能でファイルとして保存する
3. 保存したファイルをダブルクリックする

ブラウザでアプリが開きます。インストール作業も、インターネット接続も不要です。

> **この方法の制限:** ブラウザのセキュリティ上の決まりで、
> ファイルを直接開いた場合(アドレスが `file://` で始まる場合)は**マイクが使えません**。
> お手本の読み上げや、記録・グラフの機能はすべて使えます。
> 録音まで試したい場合は方法2をお使いください。

### 方法2: GitHub Pages で公開して、URLを開く(録音も使える)

GitHub が自動でアプリを組み立てて、ウェブサイトとして公開してくれます。
**最初に1回だけ**次の設定をしてください。

1. GitHub でこのリポジトリを開く
2. **Settings** タブ → 左メニューの **Pages**
3. **Source** を **GitHub Actions** に変更する
4. 変更を `main` ブランチに反映すると、自動で公開されます
5. 公開URL: `https://<あなたのユーザー名>.github.io/English-AI-System/`

> **注意:** GitHub Pages は誰でも見られる公開ページです。
> リポジトリが Private の場合、無料プランでは Pages を使えません。

### 方法3: Claude Code のセッション内で動かす

このリポジトリで Claude Code を開いて「アプリを起動して」と伝えれば、
クラウド上で起動して画面を見せてもらえます。こちらもインストール不要です。

## 対応環境

一般に公開するサービスとして、次の環境すべてで動くことを目標にしています。

| 環境 | 対象 |
|---|---|
| デスクトップ | Windows / macOS の Chrome・Edge・Safari・Firefox |
| スマートフォン | iPhone、Android(Chrome・Samsung Internet・Firefox) |
| タブレット | iPad、Android タブレット |
| アプリ内ブラウザ | LINE や SNS から開かれた場合 |

使えない機能がある環境では、**その機能だけを隠し、アプリ全体は動く**ようにしています。

> **発音スコアの方式について:** ブラウザ内蔵の音声認識は Firefox で既定オフであること、
> また端末ごとに別の認識エンジンが動くためスコアが比較できないことから、
> **サーバー側で採点する方式を推奨**しています。
> 詳細は [`docs/PRONUNCIATION_OPTIONS.md`](docs/PRONUNCIATION_OPTIONS.md) を参照してください。

## 開発者本人の端末ごとの使い分け

3つの環境を行き来する前提で作ってあります。

| 端末 | できること | 方法 |
|---|---|---|
| **会社PC**(インストール不可) | 閲覧・動作確認 | 下記「方法1」の1ファイル版、または「方法2」の公開URL |
| **Mac**(自宅) | 開発・閲覧すべて | 同上。加えて Node.js を入れれば `npm run dev` も使えます |
| **iPhone**(移動中) | 閲覧・発音練習・Claude Codeへの指示 | 「方法2」の公開URLをSafariで開く |

### iPhone で音声機能が動くか確かめる

発音練習が iPhone で使えるかどうかを確かめる診断ページを用意しています。
GitHub Pages を有効にしたあと、次のURLを iPhone の Safari で開いてください。

```
https://<あなたのユーザー名>.github.io/English-AI-System/mic-test.html
```

読み上げ・マイク・録音・音声認識の4つを順に試して、
最後に「結果をコピーする」を押した内容をチャットに貼っていただければ、
どの方式で発音評価を実装すべきか判断できます。

> **`file://` で開いても正しく確認できません。** ブラウザの決まりで、
> `https://` のページでないとマイクが使えないためです。

### iPhone で使うときのこと

- 公開URLを開いたあと、**共有ボタン → ホーム画面に追加**でアプリのように全画面で開けます
- iPhone の Safari は録音にも読み上げにも対応しているため、発音練習も使えます
  (ただし公開URL経由の場合のみ。1ファイル版ではマイクが使えません)
- 入力欄をタップしても画面が勝手に拡大しないよう調整済みです

### Mac で開発するとき

Claude Code のクラウドセッションだけで作業する場合、Mac にも何も入れる必要はありません。
手元で直接動かしたい場合のみ、Node.js 20以上を入れて次を実行してください。

```
npm install
npm run dev
```

`http://localhost:5173` が開発用のアドレスです。ここは `localhost` なのでマイクも使えます。

## ⚠️ 端末をまたぐと記録が引き継がれません

**いまの試作版の、いちばん大きな制約です。**

データは開いているブラウザの中にしか保存されないため、
会社PC・Mac・iPhone のそれぞれが**別々の記録を持ちます**。
会社で記録したものは、iPhone では見えません。

3つの端末を行き来する使い方をするなら、
**Supabase をつないでデータをサーバーに置く作業が、実質的に最優先**になります。
それまでは「1台で試す」前提でお使いください。

## この試作版でできること

### 学習者の画面

- 学習日・時間・カテゴリ(音読/単語/文法/リスニング/会話)・教材・メモの記録
- 連続学習日数、今週・累計の学習時間の表示
- 直近14日間の学習時間グラフ、カテゴリ別の内訳グラフ
- 学習履歴の一覧表示・削除
- **発音練習** — お手本の読み上げ、マイク録音、録音の聞き返し、スコア表示

### 管理者の画面

- 学習者一覧(学習時間・記録件数・連続学習日数・最終学習日・発音スコア平均)
- 期間の切り替え(直近7日 / 14日 / 30日)
- 全体および学習者別の学習時間グラフ
- 学習者をクリックすると、その人の内訳を表示
- 5日以上学習がない学習者に「要フォロー」の印を表示

## ⚠️ 正直にお伝えしておくこと

### 発音スコアは本物ではありません

画面に出る発音スコアは、**録音した音声を解析した結果ではありません。**
「録音する → 点数が出る」という画面の流れを確認するための、仮の数値です。

本物にするには、音声認識または発音評価サービスとつなぐ作業が別途必要です。
選択肢と、それぞれの長所・短所は
[`docs/PROJECT_SPEC.md` の第5章](docs/PROJECT_SPEC.md)にまとめてあります。

該当するコードは `src/lib/pronunciation.js` の1ファイルだけです。
そこを差し替えれば、他の画面のコードを変えずに本物にできる作りにしてあります。

### お手本の音声は端末によって声が変わります

ブラウザに内蔵されている読み上げ機能を使っているため、
Windows / Mac / iPhone / Android で読み上げる声が変わります。
アメリカ英語・イギリス英語を確実に指定することもできません。

### データはブラウザの中にしか保存されません

サーバーはまだ使っていません。データはブラウザの保存領域に入るため、
**別のパソコンやブラウザで開くと、記録は引き継がれません。**
複数人で使うには、次の段階で Supabase をつなぐ必要があります。

## 開発するときの情報

> ここから先は、実装作業をするとき用の情報です。
> 画面を見るだけなら読まなくて構いません。

### 必要なもの

Node.js 20 以上。
※Claude Code のクラウドセッションで作業する場合、あなたのPCには不要です。

### コマンド

| コマンド | 何をするか |
|---|---|
| `npm install` | 必要な部品(ライブラリ)をダウンロードする。最初に1回 |
| `npm run dev` | 開発用サーバーを起動する。`http://localhost:5173` で確認 |
| `npm run build` | 公開用に組み立てる。`dist/` に出力 |
| `npm run build:single` | 1ファイル版を作る。`standalone/index.html` に出力(Gitには入れない) |
| `npm run preview` | 組み立てた結果を確認する |
